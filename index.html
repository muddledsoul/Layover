Your two keys

Azure listens to you and speaks with a native voice. Claude is your tutor. Open the guides below for step-by-step setup. Keys are stored only on this phone (in the browser), never in the app's code. They stay saved through app updates. Only deleting the home-screen icon or clearing Safari website data erases them.

📘 How to get your Azure Speech key (free)
  1. Go to azure.microsoft.com/free and sign in with any Microsoft account. It asks for a phone number and a card. The card is only for identity, and the free tier never charges.
  2. Go to portal.azure.com, search Speech in the top bar, choose Speech services, then tap + Create.
  3. Fill in: Resource group → Create new "layover". Region → East US. Name → anything unique. Pricing tier → Free F0. The other tier costs money.
  4. Tap Review + create → Create, wait about a minute, then tap Go to resource → Keys and Endpoint.
  5. Copy KEY 1 into the box below. For region, enter what "Location/Region" shows (usually eastus).

⚠️ Can't copy the key on iPhone? The portal hides it and the copy icon often fails on mobile. Try these in order:
1) Tap Show Keys, then long-press the key → Select All → Copy.
2) In Safari, tap aA → Request Desktop Website and try the copy icon again.
3) Screenshot the shown key, open it in Photos, long-press the text (Live Text) → Copy. Double-check 0/O and 1/l, then delete the screenshot.
4) Copy it on your computer, paste it into Apple Notes or email it to yourself, copy it on your phone, then delete the note.

💡 If Free F0 isn't offered, you already have a free Speech resource (one per account). Use that one's key.

📗 How to get your Claude API key
  1. Go to platform.claude.com and sign in. The same email as your Claude account works, but API billing is separate from a Claude subscription.
  2. Settings → Billing: buy prepaid credit. $5 is plenty to start, and a 15-min session costs a few cents. On a Max plan you can claim free monthly API credits at claude.ai → Settings → Billing → API credits.
  3. Settings → Limits: set a low monthly spend limit (e.g. $10) so a lost phone can never cost more.
  4. Settings → API keys → Create key, name it "layover", and copy it immediately. It starts with sk-ant- and is only shown once. If you lose it, just make a new one.

💡 On iPhone, if the copy button doesn't work, use aA → Request Desktop Website.

📱 Install on your home screen
  1. Open this page in Safari. Other browsers can't install it on iPhone.
  2. Tap Share → Add to Home Screen, then open the app from the new icon.
  3. When asked for microphone access, tap Allow. If you denied it earlier, go to iPhone Settings → Safari → Microphone.

Back up & restore

⚠️ Your progress lives only inside this app on this phone. Deleting Layover from your home screen, or clearing Safari's website data, erases it for good. Save a backup to Files or iCloud Drive to keep it safe.

New phone or reinstalled the app? Import your backup file to restore progress, vocab and scores for every language.
